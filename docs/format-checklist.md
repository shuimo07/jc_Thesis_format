# 格式修改清单（逐处对照）

> 这份清单是**要改的地方的全集**。左侧定位、中间「应为」、右侧给出 Word 里的操作路径。
> 方括号里的页码 / 图号 / 表号指参考图，见 [`../reference/README.md`](../reference/README.md)。

## 使用方式

1. **先按第 0 节建样式，再按第 1–11 节逐项核对**。先建样式能让后面 90% 的项变成「套样式」一步。
2. 每一项都写成 `- [ ]`，可以直接在 GitHub 上勾进度。
3. 改完**必须**走第 12 节的渲染校验——肉眼在 Word 里翻一遍也算，但要翻到最后。

---

## 0. 动手前的三件事

- [ ] **明确范围**：格式只改版式，不动内容。内容问题（题注号写错、章节缺失、占位符没填）
      单独列出来交回作者，不要顺手改。
- [ ] **打开「显示编辑标记」**：`开始 → ¶`（或 `Ctrl+Shift+8`）。
      分节符、分页符、制表符、空格全都要看得见，否则下面一半的问题定位不到。
- [ ] **别在旧文档上逐处调格式**。旧文档的**直接格式**（run 级 `w:rPr`）会压过样式，
      清理起来比重建还慢。推荐做法：以旧文档为**内容源**，用脚本按规范重排一遍，
      再人工核对。本仓库的 `scripts/` 就是干这个的。

## 1. 页面设置

分节符在哪，比页面设置本身更容易出错。参考论文有 **3 节**：

- [ ] **第 1 节 = 封面（只有 1 页）** —— `布局 → 页面设置 → 纸张 A4`，
      页边距 **上 2.5 / 下 2.5 / 左 3.0 / 右 2.5 cm**。
- [ ] **第 2 节 = 前置部分**（声明 → 授权书 → 摘要 → Abstract → 目录），
      与第 1 节用「下一页」分节符隔开。
- [ ] **第 3 节 = 正文**（第 1 章 → 结论 → 参考文献 → 致谢），同样用「下一页」分节符。
- [ ] `布局 → 页面设置 → 版式 → 页眉和页脚：勾选「首页不同」`**不要勾**——
      封面是靠独立分节实现无页码的，不是靠首页不同。
- [ ] 页眉页脚距边界：**页眉 2.0 cm、页脚 2.2 cm**。

**不合格症状**：封面出现页码；正文页码从 1 之后连续到前置部分；页眉从封面就开始出现。

---

## 2. 页眉

- [ ] 文字：`成都锦城学院毕业论文（设计）`（全角括号）。
- [ ] 字体：**宋体五号（10.5 pt）**，**居中**。
- [ ] 文字下方 **双线**：选中页眉段落 → `开始 → 边框 → 边框和底纹 → 应用于「段落」→ 线型选双线 → 只点「下框线」`。
- [ ] 三节的页眉都要有，且**不要勾「链接到前一节」**后忘设内容。

**不合格症状**：只有一条单线；下划线是给文字加的字符底框（线只到文字宽度）；
页眉出现在封面。

---

## 3. 页脚与页码

- [ ] 页脚内容：**居中页码**，宋体五号。
- [ ] **第 1 节（封面）**：`插入 → 页码 → 设置页码格式` 不设；页脚留空，
      或勾「首页不同」并清空。**封面不参与编号。**
- [ ] **第 2 节**：`页码格式 → 编号格式 = I, II, III…`（大写罗马），`起始页码 = I`。
      必须同时勾掉「续前节」。
- [ ] **第 3 节**：`页码格式 → 编号格式 = 1, 2, 3…`（阿拉伯），`起始页码 = 1`。
- [ ] 页码位置：**居中**，不要放页眉。

**不合格症状**：正文第一页显示 7 而不是 1；前置部分显示阿拉伯数字；
封面右下角出现「1」。

---

## 4. 样式（一次性建好，后面全靠它）

- [ ] **Normal（正文）**：西文 `Times New Roman`、中文 `宋体`、**小四 12 pt**、段前段后 0。
      ⚠️ 中文字体必须通过 `开始 → 字体 → 中文字体` 设置，或直接改 `w:eastAsia`；
      只把西文字体设成宋体，中文会回落成 Word 默认字体。
- [ ] 新建并修改下列段落样式（**建议用样式而不是逐段刷格式**）：

  | 样式名 | 中文字体 | 西文 | 字号 | 加粗 | 对齐 | 缩进 | 行距 |
  |---|---|---|---|---|---|---|---|
  | 论文正文 | 宋体 | Times New Roman | 小四 12 | 否 | 两端对齐 | 首行 2 字符 | 固定值 22 磅 |
  | 一级标题 | 黑体 | Times New Roman | 小二 18 | 是 | 左 | 无 | 固定值 28 磅 |
  | 二级标题 | 黑体 | Times New Roman | 四号 14 | 是 | 左 | 无 | 固定值 22 磅 |
  | 三级标题 | 黑体 | Times New Roman | 小四 12 | 是 | 左 | 无 | 固定值 22 磅 |
  | 图题 | 黑体 | Times New Roman | 五号 10.5 | 是 | 居中 | 无 | 固定值 16 磅 |
  | 表题 | 黑体 | Times New Roman | 五号 10.5 | 是 | 居中 | 无 | 固定值 16 磅 |
  | 表格文字 | 宋体 | Times New Roman | 五号 10.5 | 表头行 | 居中 | 无 | 固定值 16 磅 |
  | 参考文献 | 宋体 | Times New Roman | 小四 12 | 否 | 两端对齐 | **无首行缩进** | 固定值 22 磅 |

- [ ] **目录样式必须是 `TOC1 / TOC2 / TOC3`**（样式的 styleId），Word 的目录域才认得。
      小四、固定行距 20 磅、缩进 0 / 2 / 4 字符、右对齐点线前导。

## 5. 标题层级（逐处）

### 5.1 章标题（一级）
- [ ] 格式：**黑体小二（18 pt）加粗、左对齐**，段前 30 磅、固定行距 28 磅。
- [ ] **每章另起一页**（`Ctrl+Enter` 或段落设置「段前分页」）。
- [ ] 编号写进标题文字：`第一章　绪论`（章号与题名之间用**全角空格**）。
      不要用 Word 自动编号——目录会多出一层，且跨节续号容易乱。
- [ ] 章标题**不要居中**（参考图里全部左对齐）。参考 [p08](../reference/pages/p08.png)、[p12](../reference/pages/p12.png)

### 5.2 章副标题
- [ ] 若章标题过长需要副标题（如「——以 …… 为例」），**副标题另起一个居中段落**，
      字号比正文大一档，且**不要设成标题样式**。
- [ ] 否则副标题会变成目录里的一条独立条目。参考 [p17](../reference/pages/p17.png)

### 5.3 节标题（二级 / 三级）
- [ ] 二级：`1.1　研究背景与意义`，黑体四号加粗、段前 5 磅。
- [ ] 三级：`1.1.1　数据来源`，黑体小四加粗、段前 7 磅。
- [ ] 编号与题名之间**全角空格**；编号后**不要**用 Tab。
- [ ] 二级/三级标题**不另起页**。

### 5.4 收尾三级
- [ ] `结论`、`参考文献`、`致谢` 全部按**一级标题**处理（黑体小二、另起页），
      但不带章号。参考 [p55](../reference/pages/p55.png), [p56](../reference/pages/p56.png), [p57](../reference/pages/p57.png)

**不合格症状**：标题居中；标题用了彩色或斜体（Word 内置 Heading 样式自带蓝色，
必须显式改回黑色）；目录里出现副标题；章标题没有另起页。

## 6. 正文段落

- [ ] **全文**正文段落：宋体小四、**首行缩进 2 字符**、两端对齐、**固定行距 22 磅**、段前段后 0。
- [ ] 缩进用「首行缩进 2 字符」而不是打空格、也不是用 Tab。
- [ ] 段与段之间**不加空行、不额外加段前段后间距**——靠行距撑开。参考 [p09](../reference/pages/p09.png)
- [ ] 列表项（`（1）（2）` 这种）的处理：整体作为一个正文段落排，**首行缩进照旧**。
- [ ] 数字与西文自动使用 Times New Roman（由样式控制，不要手动刷）。
- [ ] 上标（如 `[1]`、`3)` 引用标记）用真正的上标格式，不是改小字号。

---

## 7. 图与图题

- [ ] **图题在图的下方**，居中，黑体五号加粗。参考 [p18](../reference/pages/p18.png), [p23](../reference/pages/p23.png)
- [ ] 编号格式：`图 4-1　图片题名`（章号-序号，编号与题名之间**全角空格**）。
- [ ] **图题不缩进**，段落本身不设首行缩进。
- [ ] 插图**宽度统一 15.0 cm**（版心宽 15.48 cm 略小一点），居中，段前段后 6 磅。
- [ ] 同页多图：每张图各带自己的题注；图与图之间空一行或加段后间距。
- [ ] 整幅大图（接近页高）要单独占页，题注仍在其下方。参考 [p45](../reference/pages/p45.png)
- [ ] **图不要用「嵌入型」以外的环绕方式**（会随文字漂移）。

**不合格症状**：图题在图上方；图宽各不相同、左右不齐；题注编号写成 `图4.1`；
一张图跨页被切断。

---

## 8. 表格与表题（三线表）

- [ ] **表题在表的上方**，居中，黑体五号加粗。参考 [p19](../reference/pages/p19.png), [p20](../reference/pages/p20.png)
- [ ] 编号格式：`表 4-1　表格题名`。
- [ ] **三线表**，只有三条线：

  | 位置 | 线宽 |
  |---|---|
  | 顶线 | 单线 **1.5 磅** |
  | 表头行下 | 单线 **0.75 磅** |
  | 底线 | 单线 **1.5 磅** |
  | 竖线、内部横线 | **无** |

- [ ] 表头行那条线要加在**表头单元格的下边框**上，不是表格级「内部横框线」
      （否则每一行都有线）。
- [ ] 表格文字：宋体五号、居中；表头行加粗。
- [ ] 表格**不要设置居中对齐以外的浮动**，用「根据窗口调整表格」自动适应版心。
- [ ] 跨页长表格：设**重复标题行**，并考虑取消「允许跨页断行」保持单元格完整。
- [ ] 表格与上下正文之间留 6 磅间距。
- [ ] 表格里**不要出现空白行列**、不要用合并单元格之外的花样底纹。

**不合格症状**：有线框的网格表；表题在表下方；表头下那条线画成了 1.5 磅；
表里文字是 12 pt。

---

## 9. 目录

- [ ] 标题：`目　录`（两字之间**全角空格**），**黑体小二居中**。
- [ ] 用**目录域**而不是手工敲：`引用 → 目录 → 自动目录`，
      或在插入的域上右键 `更新域 → 更新整个目录`。
- [ ] 只收**三级**：`目录 → 自定义目录 → 显示级别 3`。
- [ ] 条目：小四、固定行距 20 磅、缩进 0 / 2 / 4 字符、
      **页码右对齐 + 点线前导**（`自定义目录 → 制表符前导符：……`）。
- [ ] 目录**不包含**封面、声明、授权书、摘要、Abstract、目录自身。
- [ ] 目录页码本身用罗马数字，属于第 2 节。
- [ ] 定稿前必须**更新整个目录**，页码才会对。参考 [p06](../reference/pages/p06.png), [p07](../reference/pages/p07.png)

**不合格症状**：目录页码是错的（还停在编辑中途的旧值）；
目录里出现「摘要」「目录」自己；一级条目和二级条目看不出层级差。

---

## 10. 封面

- [ ] 顶部：`成都锦城学院` + `本科生毕业论文（设计）`，**黑体小一（24 pt）加粗居中**，
      两行之间 6 磅间距。
- [ ] 字段区（6 行，左对齐，**四号 14 pt**）：

  | 字段 | 标签写法 |
  |---|---|
  | 题目 | `题　　目`（用全角空格把两字标签撑到 4 字宽） |
  | 二级学院 | `二级学院` |
  | 专业 | `专　　业` |
  | 学生姓名 | `学生姓名` |
  | 学号 | `学　　号` |
  | 指导教师 | `指导教师` |

- [ ] 每个字段后跟**一整条连续下划线**填充到版心右缘，字段值居中落在线上。
- [ ] 题目过长时允许折行，但折行后的文字要与**填充线起始位置**对齐（悬挂缩进）。
- [ ] 右下角：`教务处　制表` 和日期（`2025 年 5 月 4 日`），右对齐、距右边 5 字符。
- [ ] 封面**不显示页码**。

**不合格症状**：下划线只画到字段值结束、右半段断掉；
每个字段的下划线长度不一样；题目折行后压到标签上。

> 填充线是封面最容易返工的地方，具体做法和原因见
> [`notes-and-pitfalls.md`](notes-and-pitfalls.md#1-封面下划线填充线)。

## 11. 前置部分各页

### 11.1 学术诚信声明
- [ ] 标题两行居中：`成都锦城学院` / `毕业论文（设计）　学术诚信声明`，黑体二号偏大（22 pt）。
- [ ] 正文：宋体**三号（16 pt）**、**固定行距 40 磅**、**首行缩进 2 字符**、两端对齐。
- [ ] 右下「作者签名」；左下「日期：　　　年　月　日」。
- [ ] 承诺书文字**照抄学校模板，一个字都不要改**。

### 11.2 版权使用授权书
- [ ] 版式同声明页。
- [ ] 底部**作者与指导教师两栏并排**：
      `作者签名：________　指导教师签名：________`，
      下一行两条独立的日期栏（四号 14 pt）。参考 [p03](../reference/pages/p03.png)

### 11.3 摘要 / Abstract
- [ ] 中文：`摘要：` 加粗小四 + 内容小四；换行后 `关键词：` 加粗 + 3–5 个词，
      **分号分隔**，末词后不加标点。
- [ ] 英文：`Abstract:` 加粗 + `Key Words:` 加粗，英文 Times New Roman 小四。
- [ ] 摘要正文格式与论文正文一致（固定行距 22 磅、首行缩进 2 字符）。
- [ ] **摘要页在最前面**，且各自**单独起页**。

---

## 12. 参考文献

- [ ] 一级标题「参考文献」，另起页，黑体小二。
- [ ] 条目：宋体小四、**顶格（无首行缩进）**、固定行距 22 磅、两端对齐。
- [ ] 序号用 `[1]`、`[2]`，**顶格**，与正文之间不留多余空格。
- [ ] 中英文混排时英文用 Times New Roman。
- [ ] 参考文献**不按章分**，全文连续编号。
- [ ] **正文里的引用标注与文献表一一对应**（这条属内容，但要提醒作者）。
- [ ] 条目长短不一导致行距不齐时，检查是不是某条里混进了 11 pt 或 10.5 pt 的字。

参考 [p56](../reference/pages/p56.png)

---

## 13. 结论与致谢

- [ ] 「结论」按一级标题处理、另起页；正文格式与一般正文一致。
- [ ] 「致谢」同上。
- [ ] 两者都**不是**章，不编号。

参考 [p55](../reference/pages/p55.png), [p57](../reference/pages/p57.png)

## 14. 收尾一致性检查（务必逐条做）

- [ ] **全文替换检查字体**：`开始 → 替换 → 更多 → 格式 → 字体`，
      搜 `宋体 + 五号`、`黑体 + 四号` 等异常组合，确认没有漏网的手工格式。
- [ ] **行距抽查**：随机跳到 10 个正文页，用「段落」对话框输入框看是否都是「固定值 22 磅」。
- [ ] **页码抽查**：前置部分最后一页、正文首页、正文最后一页、致谢页，四处页码都要对。
- [ ] **目录重算**：`Ctrl+A → F9 → 更新整个目录`，然后**翻一遍目录页码是否与实际一致**。
- [ ] **图表编号连续性**：`图 4-1 … 图 4-n`、`表 4-1 …` 中间不能跳号、不能重号
      （参考论文里出现过同一图号重复两次）。
- [ ] **图/表题注是否挂对了对象**：图号配图、表号配表，不要出现「图 4-2」实际是三线表。
- [ ] **分页检查**：章标题不要孤立在页面底部；表格不要只剩表头一行留在上一页。
- [ ] **页边距**：`布局 → 页边距 → 自定义`，三节都必须一致。
- [ ] **导出 PDF 通读**：导出后逐页翻，PDF 是最终形态，
      Word 视图里看不出的问题（页码、分页、断表）在 PDF 里会暴露。

### 一次搞定的命令（需要本机装 Word）

```bash
# 用 Word 刷新所有域（目录页码）+ 导出 PDF + 逐页 PNG
python scripts/refresh_and_export.py 你的论文.docx --raster
```

## 附：Word 批量操作速查

| 想做的事 | 路径 |
|---|---|
| 看分节符/分页符/制表符 | `开始 → ¶`（`Ctrl+Shift+8`） |
| 一次性选中所有同类样式段落 | `开始 → 样式 → 右键样式 → 选择所有 N 个实例` |
| 清掉某段的直接格式 | `Ctrl+Space`（清除字符格式）、`Ctrl+Q`（清除段落格式） |
| 更新目录页码 | 点目录 → `F9` → 更新整个目录 |
| 显示域代码 | `Alt+F9` |
| 改样式而不改正文 | 样式库右键 → 修改（**不要**用格式刷，格式刷刷的是直接格式） |
| 表格线宽 | 选中表格 → `设计 → 边框 → 边框和底纹 → 宽度`（1.5 磅 / 0.75 磅） |
| 重复标题行 | 选中表头行 → `布局 → 重复标题行` |
