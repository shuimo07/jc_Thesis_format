## 从这 57 页里能直接量到的东西

| 参数 | 怎么量 | 参考值 |
|---|---|---|
| 固定行距 | 相邻两行墨迹**顶部**间距 | 22 磅 ≈ 7.76 mm；20 磅 ≈ 7.06 mm；40 磅 ≈ 14.1 mm |
| 字号 | 单行汉字墨迹高度 `h` | `pt = h_mm ÷ 0.3246`（= 0.3528 × 0.92） |
| 首行缩进 | 段首到版心左缘 | 2 字符 = 2 × 字号 pt |
| 版心宽 | 正文最长行的左右墨迹边界 | 15.48 cm |
| 三线表线宽 | 横线的像素厚度 | 1.5 pt / 0.75 pt |

```bash
# 例：量第 19 页（三线表）的横线位置与线宽
python scripts/measure_reference.py table reference/pages/p19.png
# 例：量第 09 页（纯正文）的行距与缩进
python scripts/measure_reference.py lines reference/pages/p09.png
```
